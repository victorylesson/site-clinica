## 📋 Sobre o Projeto

Site institucional criado como exemplo de entrega para clínicas médicas, odontológicas ou de estética. O projeto demonstra como uma clínica pode ter uma presença digital confiável, profissional e que facilita o agendamento de consultas por parte dos pacientes.

---

## ✨ Funcionalidades

- Página institucional com identidade visual limpa e transmissora de confiança
- Apresentação dos serviços e especialidades oferecidas
- Perfil dos profissionais da equipe
- Formulário e botão de agendamento de consultas
- Integração com WhatsApp para contato direto
- Seção de depoimentos de pacientes
- Informações de localização e horários de atendimento
- Design 100% responsivo (mobile, tablet e desktop)
- Otimizado para SEO local

# Abra o arquivo index.html no navegador
# Ou use a extensão Live Server no VS Code
